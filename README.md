Task 2 – Simulation Using Sensors

Project Overview

This project is a sensor-based simulation developed using Wokwi as part of the CodeAlpha internship tasks.

Objective

To simulate sensors and demonstrate how sensor data can be collected and used by a microcontroller.

Tools Used

- Wokwi
- Arduino
- Sensors
- Embedded C/C++

Simulation

The complete circuit and code are simulated using Wokwi.

Files

- "sketch.ino" – Arduino source code
- "diagram.json" – Wokwi circuit configuration

Platform
-
Wokwi: Online electronics simulation platform
